# ABB Hardware Module

> [!NOTE]
> Developed and maintained by Intrinsic. Not an official product of ABB.

## Overview

This directory contains the ICON Hardware Module (HWM) implementation for ABB robots communicating via ABB's robot controller interface.

## Supported Robot Models & Device Targets

| Robot Model | `intrinsic_hardware_device` Bazel Target | Asset ID |
| :--- | :--- | :--- |
| **IRB 1300-10/1.15** | `:abb_irb_1300_10_115_hardware_module` | `ai.intrinsic.abb_irb_1300_10_115_hardware_module` |

## Documentation

For documentation on setting up ABB robots with Intrinsic Flowstate, see the [ABB Setup Guide](https://flowstate.intrinsic.ai/docs/guides/commission_solution/set_up_robot/abb_rws_egm_setup/).
